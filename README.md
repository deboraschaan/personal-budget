# 💸 Personal Budget API — Express.js Project

A fully functional REST API for managing a personal budget using the principles of [Envelope Budgeting](https://www.thebalancemoney.com/what-is-envelope-budgeting-1293682#toc-how-envelope-budgeting-works). This project follows industry best practices for endpoint naming, proper HTTP status codes, and includes data validation to help users avoid overspending.

> 🚀 Built with a focus on clean code, modular structure, and scalability.  
> 🧩 Future-ready: this API will serve as the backend for a complete budgeting app with a React frontend.

---

## Project Objectives

➡️ Build a RESTful API with Express.js

➡️ Create, read, update, and delete budget envelopes

➡️ Update envelope balances and distribute funds across categories

➡️ Use Git for version control and commit discipline

➡️ Navigate and test using CLI and Postman

---

## Tools & Technologies

- JavaScript (ES6+)
- Node.js
- Express.js
- Postman
- Git & GitHub
- Command Line

---

## Features

- Create custom budget envelopes (categories)
- Set spending limits for each envelope
- Update envelope balances individually or distribute one balance across multiple envelopes
- Built-in input validation and error handling

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/deboraschaan/personal-budget
   cd personal-budget
   
2. Install dependencies:

    ```bash
    npm install

3. Run the server:

    ```bash
    npm start

4. Access the API at:

    ```bash
    http://localhost:3000/api/v1

Use Postman or your preferred tool to test the available endpoints.
